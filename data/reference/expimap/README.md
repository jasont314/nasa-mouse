# expiMap Reference Metadata

This directory contains the small reference-data snapshot retained from the
official expiMap reproducibility repository at commit
`295ac3c0fff29b8c9e33bc412c8e8282201b0be2`:

- Reactome v4 and v7.5.1 gene-set files;
- PanglaoDB marker gene sets;
- the upstream marker collection and parsing notebook.

NASA workflow code uses these files from `paper_metadata/`. The upstream license
is preserved as `UPSTREAM_LICENSE`. Current mouse Reactome architecture data remain
under `data/pathways/`.
